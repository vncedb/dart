# 📱 Overview

**DART (Daily Accomplishment Report Tool)** is a mobile productivity application designed to help professionals track daily accomplishments, manage work logs, and generate structured reports efficiently.

It provides secure cloud synchronization, report exports, and premium features via subscription.

---

# ✨ Key Features

## 📋 Work Tracking
- Daily accomplishment logging
- Job/task categorization
- Timeline-based activity view
- Time tracking support

## 📊 Report Generation
- Structured professional report formatting
- CSV export support
- Downloadable summaries
- Preview before export

## 🔐 Authentication & Security
- Supabase authentication
- Secure session handling
- Biometric lock support
- Row Level Security (RLS)

## ☁️ Cloud Sync
- Real-time Supabase database sync

# 📂 Project Structure

```
app/                → Screens & routes
components/         → Reusable UI components
constants/          → Static configurations
context/            → Global providers
hooks/              → Custom hooks
lib/                → Supabase client & services
services/           → Business logic layer
supabase/functions/ → Edge functions
utils/              → Export & report utilities
```
